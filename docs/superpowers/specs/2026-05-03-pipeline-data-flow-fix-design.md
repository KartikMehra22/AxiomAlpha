# AxiomAlpha — Pipeline Data-Flow Fix

**Status:** Draft
**Date:** 2026-05-03
**Author:** Kartik Mehra
**Scope:** Surgical fix to the 15-notebook pipeline so every notebook reads real upstream outputs and no notebook fabricates data with `np.random`.

---

## 1. Problem

The 15-notebook AxiomAlpha pipeline does not actually chain end-to-end. Two distinct bug classes:

**Class A — Missing data-load cells (NameError on fresh run).**
NB02, NB03, NB04, NB06, NB07 reference dataframes (`prices`, `macro`, `sector_map`, `features_with_graph`, `regimes`, `dynamic_metrics`, `model_dir`, `model_vol`, `model_reg`, `scaler`, `features_df`) before defining or loading them. The notebooks crash with `NameError` on a fresh kernel. The CSVs in `data/processed/` exist only because an earlier working version was run.

**Class B — Deliberate `np.random` data fabrication.**

| NB | Random injection | What it should read |
|---|---|---|
| 09 | `embeddings_matrix = np.random.rand(N, 128)` | real sentence-transformer embeddings of synthetic news |
| 10 | `final_signals['sentiment_risk_flag'] = np.random.choice([T,F], ...)` | derived from real FinBERT sentiment |
| 11 | `mu_historical/ml/sent/rev = np.random.normal(...)`; `cov = np.cov(np.random.randn(...))`; `sys_scores = np.random.uniform(...)`; `sent_scores = np.random.normal(...)` | `master_signals.csv`, `sentiment_features.csv`, `risk_metrics.csv`, `systemic_risk_scores.csv`, plus `LedoitWolf` covariance from real returns |
| 13 | `current_regime = np.random.choice(['Bull','Bear','Volatile'])`, `confidence`, `direction_prob`, `vol_forecast`, `sentiment_mean`, `news_volume` all randomized | each agent reads its assigned CSVs |
| 14 | `returns = pd.DataFrame(np.random.randn(100, 10), columns=['TICKER_0'..])` | real `log_returns`, real `optimal_weights` |
| 15 | fallback `np.random.rand(5)` portfolio; equity curves all `np.random.normal` | real `optimal_weights.csv`, `equity_curves.csv`, `performance_metrics.csv` |

Plus systemic issues: f-string syntax bugs in `plt.savefig` across multiple notebooks; `Date` vs `date` schema drift; documented "Claude API" usage that never imports `anthropic`; look-ahead bias risks (`bfill` on prices, same-day sentiment merge, regime feature without lag); GARCH α+β reported at 0.998 with no validity check.

**Net effect on headline numbers:**
- Sharpe 1.018 — backtest math is honest (NB12 reads real prices) but the *weights* it applies came from NB11's randomly-generated signals.
- Direction AUC 0.545 — target construction is correct, but the notebook can't run as-written.
- Sentiment IC 0.0503 — derived from real FinBERT scoring, but with same-day join (lookahead).
- "Claude generates explanations" — never executed; agents use string templates.

## 2. Goals & non-goals

**Goals**
- Every notebook reads real upstream outputs through a single source of truth (`src/io/loaders.py`).
- No notebook fabricates data with `np.random` for any quantity that should come from upstream.
- One command (`python run_all.py`) executes the full pipeline end-to-end, fail-fast, deterministic.
- Headline numbers in `RESULTS.md` are regenerated by the live pipeline, not hand-edited.
- README claims match what the code actually does.

**Non-goals (later, "make it big" phase)**
- Real news API integration (NewsAPI/Finnhub) — keep synthetic news with documented limitation.
- Long/short optimization — keep long-only.
- Move pipeline logic to `src/pipeline/` — keep notebook-driven architecture.
- Real Claude API integration for agent explanations — keep templates.
- Live data streaming, RL execution, GPU graph frameworks.

## 3. Architecture

15 notebooks form a linear pipeline that chains exclusively through CSV/JSON/PKL files in `data/raw/` and `data/processed/`.

A new module `src/io/loaders.py` is the single source of truth for every read. No notebook reads files directly anymore. No notebook fabricates data with `np.random` for upstream quantities. The only legitimate `np.random` uses are: optimizer warm-starts, Monte Carlo stress simulations explicitly labeled as such, and viz decoration — all under `np.random.seed(42)` and tagged `# noqa: pipeline-check` for the smoke test.

### Invariants

1. Every notebook starts with a `# Load Inputs` cell that uses `from src.io.loaders import ...` and nothing else for I/O.
2. No notebook fabricates a quantity that should come from upstream.
3. Every loader validates schema before returning; missing file raises `PipelineDataError` with a clear "run NB-X first" message.
4. Date column is always named `Date` (capitalized), `datetime64[ns]`, no timezone, date-only.
5. `np.random.seed(42)` is set at the top of every notebook with any stochastic component.

## 5. New / changed files

### 5.1 `src/io/loaders.py` (new, ~150 lines)

Single source of truth for every read. Conventions:
- Date column always `Date`, `datetime64[ns]`, no tz, date-only.
- Wide-format frames (one column per ticker) use `Date` as index.
- Long-format frames have `Date` and `ticker` as first columns, sorted by `(ticker, Date)`.
- Every loader validates against an explicit schema; raises `PipelineDataError` on failure.
- No fallbacks, no synthetic generation. Missing file = hard error with message naming the producer notebook.

Functions:

```
load_prices, load_macro, load_sector_map,
load_log_returns, load_simple_returns, load_features_raw, load_features_normalized,
load_feature_scaler, load_risk_metrics, load_regimes,
load_mst_edges, load_dynamic_graph_metrics, load_centrality_scores,
load_community_assignments, load_systemic_risk_scores, load_features_with_graph,
load_granger_causality, load_leader_follower, load_graph_intelligence,
load_ml_signals, load_models, load_master_signals, load_signal_explanations,
load_synthetic_news, load_sentiment_features, load_embeddings,
load_faiss_index, load_rag_documents,
load_optimal_weights, load_equity_curves, load_performance_metrics,
load_attribution_results, load_regime_performance,
load_backtest_results, load_pipeline_output
```

Helper utilities:
- `_find_project_root()` — walks up looking for `AxiomAlpha` directory.
- `_require(path, producer_nb)` — raises `PipelineDataError` if missing.
- `_validate(df, required_cols, name, monotonic_index)` — schema check, raises if violated.
- `PipelineDataError(FileNotFoundError)` — base exception.

### 5.2 `configs/settings.py` (modify existing)

Centralizes: ticker list, date range, random seed, model hyperparameters (RF, XGBoost, GARCH), graph window size, NLP model names, optimizer params (risk aversion, max weight, long-only flag, CVaR alpha), backtest config (rebalance frequency, transaction cost bps), and path constants.

### 5.3 `run_all.py` (new, ~40 lines)

Papermill-driven orchestrator. `python run_all.py` executes all 15 notebooks in order, in-place, fail-fast on first error. Passes `RANDOM_SEED` parameter to each notebook.

### 5.4 `scripts/check_pipeline.py` (new, ~50 lines)

Greps every notebook for forbidden patterns:
- `np.random.normal/randn/choice/uniform/rand` (data fabrication)
- `parse_dates=['date']` (schema drift)
- `pd.read_csv(` (must use loaders)
- Missing `from src.io.loaders` import (except NB01)

Allowlist mechanism: cells tagged `# noqa: pipeline-check` are skipped (for legitimate Monte Carlo, optimizer warm-start, and similar).

### 5.5 `scripts/check_determinism.py` (new, ~30 lines)

Hashes `data/processed/*.csv` after two consecutive runs of `run_all.py`; fails if any artifact differs (modulo timestamps in JSON).

### 5.6 `requirements.txt` (rewrite)

Pin every version with `==`. Remove `anthropic` (unused). Keep `langgraph` (used by NB14). Drop `langchain` (unused).

## 6. Correctness audit (look-ahead bias, walk-forward, statistical validity)

These are the quiet bugs — they don't crash, they just inflate headline numbers. Each fix has an assertion.

### 6.1 Look-ahead bias fixes

| Where | Current | Fix |
|---|---|---|
| NB02 price cleaning | `prices.ffill().bfill()` | `prices.ffill()` only (no backfill) |
| NB02 rolling features | `r.rolling(20).std()` | `r.rolling(20).std().shift(1)` for predictor features |
| NB10 sentiment merge | same-day join | `sentiment.shift(1).merge(...)` (1-day lag) |
| NB06 regime as feature | `df['regime_encoded']` | `df['regime_encoded'].shift(1)` |
| NB11 mu construction | direct read | rolling 20-day mean of `alpha_signal.shift(1)` |
| NB12 rebalance | weights at `t` from data ≤ `t` | weights at `t` from data ≤ `t-1` |

After each, an explicit assertion (e.g., `assert features.index.max() == log_returns.index.max()`).

### 6.2 Walk-forward integrity (NB12)

Hard assertion in the rebalance loop: at each rebalance date `t`, weights came from data strictly < `t`. Either holds (genuine walk-forward) or fails loudly.

### 6.3 GARCH validity (NB03)

```
for ticker, fit in garch_results.items():
    persistence = fit.params['alpha[1]'] + fit.params['beta[1]']
    if persistence >= 1.0:
        warnings.warn(f"{ticker}: GARCH non-stationary (α+β={persistence:.4f})")
```

### 6.4 Train/test discipline (NB06)

`TimeSeriesSplit` already in use. Add explicit per-fold assertion: `train_dates.max() < test_dates.min()`. Fit `StandardScaler` on train indices only.

### 6.5 Sentiment IC verification (NB10)

After applying `shift(1)`, recompute IC and write to `nlp_metrics.json`. Expected: original 0.0503 was likely lookahead-inflated; post-lag value will be smaller (likely 0.005–0.025). Whatever it is, it's the truthful number.

### 6.6 Determinism

After all changes, two consecutive runs of `python run_all.py` produce bit-identical CSVs (`scripts/check_determinism.py` enforces).

### 6.7 Expected impact on headline numbers

The README numbers will likely change after fixes:
- **Sharpe 1.018 → likely 0.6–0.9** (was on noise; real signals lower but still > equal-weight baseline expected).
- **Sentiment IC 0.0503 → likely 0.005–0.025** (post-lag).
- **AUC 0.545 → ~unchanged** (target was correct).
- **Regime F1 0.78 → ~unchanged** (NB03 logic OK).

Whatever numbers come out are truthful. README links to `RESULTS.md` so docs and code never drift again.

## 9. Risks

**R1: Pinning dependencies breaks an existing working version.**
Mitigation: pin to versions confirmed by `pip freeze` after a successful `run_all.py` run.

**R2: Real sentence-transformer embeddings are slower than random ones.**
Mitigation: cache `embeddings.npy` to disk; only re-embed if `synthetic_news.csv` changes. NB09 reuses cache.

**R3: Real signals in NB11 produce a much lower Sharpe than 1.018.**
Mitigation: this is the goal — truthful numbers. RESULTS.md is auto-generated; README links to it. No hand-edited claims to defend.

**R4: Walk-forward assertion in NB12 fails on first run.**
Mitigation: that means we found a real bug. Diagnose and fix at that point.

**R5: GARCH α+β ≥ 1 warning fires for many tickers.**
Mitigation: surface honestly in `risk_metrics.csv` metadata; consider switching to integrated-GARCH or EGARCH if persistent. Document in NB03 README.

**R6: Determinism check fails due to a hidden seed leak (e.g., multi-threaded XGBoost).**
Mitigation: set `n_jobs=1` for XGBoost / RF in deterministic runs; document the trade-off.
