# AxiomAlpha

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/line-chart.svg" width="16" height="16" align="absmiddle"> A walk-forward quantitative research pipeline that combines GARCH volatility modelling, correlation-network analysis, ML alpha signals, and CVXPY portfolio optimisation across a 30-ticker US equity universe (2019–2024).

The project is laid out as 15 sequential notebooks plus a small `src/` library that holds the canonical math. Every number in `data/processed/RESULTS.md` is regenerated by `python run_all.py`; nothing in this README is hardcoded.

## What it actually does

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/database.svg" width="16" height="16" align="absmiddle"> **Phase 1 — Data.** Pulls split- and dividend-adjusted daily closes for 30 large-cap US equities and five macro series (VIX, S&P 500, 10Y yield, gold, WTI) from yfinance/FRED. Universe is defined in `configs/settings.py:STOCK_UNIVERSE`; NB01 imports from there.

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/sigma.svg" width="16" height="16" align="absmiddle"> **Phase 2–3 — Stats.** Cleans prices (forward-fill only, no future leakage), computes log returns, builds rolling momentum/volatility/drawdown features, runs Jarque–Bera, fits GARCH(1,1), and bins regimes by expanding-quantile market volatility.

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/share-2.svg" width="16" height="16" align="absmiddle"> **Phase 4–5 — Graph.** Builds rolling 60-day correlation matrices and the Mantegna minimum spanning tree, runs Louvain/Girvan–Newman/label-propagation community detection, computes per-day MST centrality (degree, betweenness, eigenvector, PageRank) for every (Date, ticker), and runs Granger causality to derive lead/follower labels.

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/cpu.svg" width="16" height="16" align="absmiddle"> **Phase 6–7 — ML.** Trains time-series-CV XGBoost / Random Forest / Ridge models on the price + macro + graph feature matrix. Targets are direction (binary), next-day volatility (regression), and regime (multiclass).

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/file-text.svg" width="16" height="16" align="absmiddle"> **Phase 8 — NLP.** Generates synthetic news headlines, scores them with FinBERT, computes information coefficient against forward returns, and embeds them into a FAISS index. The NLP signal is honest about being synthetic — see *Limitations*.

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/scale.svg" width="16" height="16" align="absmiddle"> **Phase 9–10 — Backtest.** Walk-forward monthly rebalancing for Equal Weight, Markowitz, and AxiomAlpha. Each fold computes its own regime label and per-asset systemic-risk score from the training window only — no full-sample artifacts leak into the test period. Costs combine a 5-bps linear bid/ask charge with a square-root market-impact term.

<img src="https://cdn.jsdelivr.net/npm/lucide-static@latest/icons/network.svg" width="16" height="16" align="absmiddle"> **Phase 11 — Orchestration.** Seven agent nodes (Data / Quant / Graph / ML / NLP / Risk / Strategy) wired through LangGraph (with a manual-sequential fallback if LangGraph isn't installed). Each node reads its phase's outputs and writes a JSON-serialisable summary into shared state; the final state is persisted to `pipeline_output.json`. Explanations are templated, not LLM-generated.

## Results

Headline numbers live in [`data/processed/RESULTS.md`](data/processed/RESULTS.md) and are rewritten by every run. The README does not duplicate them — that's how every previous version of this file ended up disagreeing with the artifacts.

A quick orientation, with the caveat that the live numbers may drift:

- AxiomAlpha sits between Markowitz and the equal-weight baseline on raw return but wins on Sharpe (lower realised vol) and clearly on max drawdown.
- Equal Weight is genuinely competitive — the strategy edge is measured *against it*, not against handpicked benchmarks.
- Sentiment IC hovers near zero. Synthetic news has no real predictive signal; what's being measured is FinBERT's response to the templates.

## Universe

30 US large-caps, six GICS sectors of five tickers each. Defined in `configs/settings.py:STOCK_UNIVERSE`:

| Sector       | Tickers                              |
|--------------|--------------------------------------|
| Technology   | AAPL, MSFT, NVDA, GOOGL, META        |
| Financials   | JPM, BAC, GS, MS, WFC                |
| Healthcare   | JNJ, UNH, PFE, ABBV, MRK             |
| Energy       | XOM, CVX, COP, SLB, EOG              |
| Consumer     | AMZN, TSLA, HD, MCD, NKE             |
| Industrials  | BA, CAT, GE, MMM, UPS                |

Date range: `2019-01-01` → `2024-12-31`, ~1,500 trading days after market-calendar filtering. NB01 forward-fills isolated holes; tickers with >5% missing pre-fill are dropped.

`data/raw/sector_map.json` is regenerated from `STOCK_UNIVERSE` and committed; it's the only piece of raw data tracked in git.

## Running it

```bash
# 1. clone + install (Python 3.11+)
git clone https://github.com/KartikMehra22/AxiomAlpha.git
cd AxiomAlpha
pip install -r requirements.txt

# 2. set environment (only FRED_API_KEY is required by NB01)
cp .env.example .env
# edit .env to add your free FRED key from https://fred.stlouisfed.org/docs/api/api_key.html

# 3. run end-to-end (10–30 min; hits yfinance + FRED)
python run_all.py                    # full pipeline, NB01 → NB15
python run_all.py --from 02          # resume from NB02 (uses cached data/raw/)
python run_all.py --skip-check       # skip the static check_pipeline.py gate

# 4. verification gates
python scripts/check_pipeline.py     # no fabricated data, no direct file reads
python scripts/check_determinism.py  # byte-identical CSV/NPY/JSON across two NB02→NB15 runs
pytest                                # 108 unit/property tests
```

## Limitations

Things this codebase explicitly does not do. Static checks and tests enforce the rules where possible.

**Data.** News headlines (NB08) are synthetic templates — FinBERT scoring and sentence-transformer embeddings are real, but the underlying text is generated, so the sentiment IC is informative about FinBERT's behaviour, not real-world media-driven alpha. The 30-ticker universe is a hard ceiling for in-process `networkx`; scaling past ~100 names needs a streaming/GPU graph stack such as cuGraph. NB01 itself is non-deterministic because yfinance returns slightly different bytes across calls (split-adjustment backfills); the determinism gate therefore runs `--from 02` against a frozen `data/raw/`.

**Modelling.** Shorts are off by default but the flag (`OPT_LONG_ONLY` in `configs/settings.py`) is wired through both Markowitz and AxiomAlpha; flipping it to `False` activates `(-MAX_WEIGHT, MAX_WEIGHT)` bounds. Transaction costs include a 5-bps linear charge plus a square-root market-impact term controlled by `SLIPPAGE_BPS`; there is no separate liquidity model. Walk-forward folds compute their own regime label and per-asset systemic-risk score from the training window only — no full-sample artifacts leak in.

**Reproducibility.** The pipeline is deterministic from NB02 onward given a frozen `data/raw/`. `scripts/check_determinism.py` hashes every CSV / NPY / JSON across two runs and fails on any byte difference (timestamps in JSON are stripped before hashing — see `VOLATILE_JSON_KEYS`). All model RNGs derive from `configs.settings.RANDOM_SEED`; hardcoded `random_state=42` literals are forbidden by `scripts/check_pipeline.py`.

## Implementation notes

- `langchain` and `anthropic` are intentionally not dependencies. Agent explanations are templated; the orchestration framework is LangGraph (state machine) without LLM calls.
- The canonical Sharpe / Sortino / Calmar / drawdown / `compute_portfolio_returns` implementations live in `src/quant_core/__init__.py` and are regression-tested in `tests/test_finance_formulas.py` — including specifically against the historical `rf * 252` Sharpe bug pattern.
- `src/io/loaders.py` is the only place that calls `pd.read_csv` / `joblib.load`. Every notebook must import from there; the static check fails any direct file read.
- Lower-case `tickers` in NB01's save cell is a legacy alias kept around so the cell doesn't `NameError` on a fresh kernel; the canonical universe is `configs.settings.TICKERS`.
